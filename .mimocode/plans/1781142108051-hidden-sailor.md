# 生成 Shield 权限

## Context

项目已有 2 个 Filament 面板（admin、platform），FilamentShieldPlugin 已安装但权限表为空（0 条记录）。需要为所有面板实体生成权限。

## 步骤

### 1. 为 Admin 面板生成权限

```bash
php artisan shield:generate --all --panel=admin --no-interaction
```

这会为 `app/Filament/Resources/` 下的所有 Resource、`app/Filament/Pages/` 下的所有 Page、`app/Filament/Widgets/` 下的所有 Widget 生成权限和策略。

### 2. 为 Platform 面板生成权限

```bash
php artisan shield:generate --all --panel=platform --no-interaction
```

为 `app/Filament/Platform/Resources/`、`app/Filament/Platform/Pages/`、`app/Filament/Platform/Widgets/` 下的所有实体生成权限。

### 3. 确认 super-admin 角色已关联所有权限

检查数据库中 `roles`、`permissions`、`role_has_permissions` 表，确保 super_admin 角色拥有所有新生成的权限。

## 验证

- 检查 `permissions` 表条目数 > 0
- 检查 `role_has_permissions` 表 super_admin 角色关联了所有权限
- 访问 `/admin` 确认资源列表正常显示
